# Love Forward ABA Website

This is a simple static website designed for GitHub Pages.

## Before publishing
1. Open `contact.html` and replace `YOUR-EMAIL@example.com`.
2. Replace the placeholder phone number and service area.
3. Review all wording and update anything that does not match your final services/policies.
4. The logo is in `assets/love-forward-logo.png`.

## Files
- index.html — Home
- about.html — About
- services.html — Services
- families.html — For Families
- contact.html — Contact
- style.css — Site design
- script.js — Mobile navigation
- assets/ — Logo

## GitHub Pages
Create a GitHub repository, upload all files/folders, then go to:
Settings → Pages → Deploy from a branch → main → /(root) → Save.
GitHub will provide the published URL.
